# 🌷 NAYLA'S FASHION AND CRAFT

**Gaya Manis, Cerita Lokal.**

## 📌 Deskripsi Website

Nayla's Fashion and Craft merupakan website toko fashion dan kerajinan lokal yang menghadirkan berbagai pilihan busana, aksesori handmade, dan produk kerajinan dengan desain menarik.

Website ini mengusung konsep soft pastel, aesthetic, feminim, dan elegan dengan tujuan memperkenalkan produk fashion serta karya kerajinan lokal kepada masyarakat.

## 🎀 Fitur Website

Website ini memiliki beberapa halaman utama:

1. **Beranda (index.html)**
   - Tampilan utama website.
   - Informasi singkat tentang toko.
   - Produk favorit.
   - Tombol untuk menjelajahi koleksi.

2. **Tentang Kami (tentang.html)**
   - Profil usaha.
   - Visi dan misi.
   - Informasi mengenai Nayla's Fashion and Craft.

3. **Layanan (layanan.html)**
   - Informasi produk fashion dan kerajinan.
   - Blus Pastel.
   - Dress Floral.
   - Tote Bag Craft.
   - Daftar harga dan rincian produk.

4. **Galeri (galeri.html)**
   - Kumpulan foto fashion.
   - Inspirasi outfit.
   - Koleksi kerajinan tangan.
   - Inspirasi produk handmade.

5. **Kontak & Pemesanan (kontak.html)**
   - Informasi kontak.
   - Formulir pemesanan produk.

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3

Website dibuat menggunakan HTML dan CSS tanpa menggunakan JavaScript.

## 🎨 Konsep Desain

- Warna utama: Soft Pink, Cream, Beige, dan Pastel.
- Gaya desain: Aesthetic, Feminine, Minimalist.
- Elemen dekorasi: Bunga, pita, boneka beruang, dan ornamen lucu.
- Tampilan: Sederhana, menarik, dan mudah digunakan.

## 🚀 Cara Menjalankan Website

1. Siapkan seluruh file HTML dan CSS.
2. Buat folder bernama `images`.
3. Masukkan seluruh gambar sesuai daftar nama file.
4. Pastikan semua file berada dalam satu folder proyek.
5. Buka file `index.html` menggunakan browser.
6. Gunakan menu navigasi untuk menjelajahi halaman website.
